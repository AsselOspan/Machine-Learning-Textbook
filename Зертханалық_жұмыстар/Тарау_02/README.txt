№2 ЗЕРТХАНАЛЫҚ ЖҰМЫС

Деректерді алдын ала өңдеу: жетіспейтін мәндерді, санаттық белгілерді өңдеу, деректерді масштабтау және нормалау.

Құрамында labs/lab02.ipynb, labs/lab02.py, requirements.txt және datasets/synthetic_equipment_load.csv бар. Барлық 500 жол мен микрокесте — оқу үшін жасалған синтетикалық деректер. Генератор seed 2026 пайдаланады.

Python 3.12 ортасында іске қосу
1. Осы Тарау_02 каталогына өтіңіз.
2. python -m venv .venv
3. Жүйеңізге сәйкес ортаны белсендіріңіз.
4. python -m pip install -r requirements.txt
5. Скрипт: python labs/lab02.py
6. Notebook интерфейсі үшін: python -m pip install jupyterlab
7. jupyter lab командасын орындап, labs/lab02.ipynb файлын ашыңыз. Таза ядродан барлық ұяшықты ретімен іске қосыңыз.

Алғашқы кітапхана орнатылымына интернет қажет. Деректер мен есептеулер кейін жергілікті орындалады. Скрипт суреттерді figures, CSV-ді datasets каталогына жазады. Notebook өзінің жұмыс каталогында lab02_artifacts бумасын құрады.

Негізгі қағида — алдымен train/test бөлуі, кейін түрлендірулерді тек train-де оқыту. Тест тұрақты бекітілген салыстыру үшін пайдаланылады. Нәтижелер осы синтетикалық генераторға, бөлінуге және бекітілген кітапхана нұсқаларына қатысты.

Орысша бастапқы материал — 2-тарау мен №2 зертханалық жұмыс, Оспан Ә.Ғ. Қазақша оқу мәтіні Мәтіндер/ch02.md файлында сақталады. Деректер, API атаулары және сандық параметрлер сақталған.
