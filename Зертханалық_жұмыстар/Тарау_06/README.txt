6-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНЫҢ МАТЕРИАЛДАРЫ

Қазақша жинаққа ескерту: төмендегі бастапқы тексеру мен баспа сипаттамалары орысша түпнұсқа жинақтың README мәтінінен аударылған. Орысша PDF/DOCX бұл жинаққа енгізілмеген. Қазақша файлдардың нақты орындалу дәлелдері _work/qa/ch06_kernel.json және _work/translation_notes/ch06.md файлдарында бөлек берілген.

Бұл — 15 тараулы толық оқулық емес, бір тараудың жинағы.

Құрамы: тараудың PDF файлы, labs бумасындағы Notebook және скрипт,
requirements.txt, сондай-ақ datasets ішіне енгізілген болса, деректер жиынтығы.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны жүйеңізге тән стандартты тәсілмен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab06.ipynb ашып, жоғарыдан төмен орындаңыз.
   Jupyter қолданбайтын балама: python labs/lab06.py

Скрипт салыстырмалы шығыс figures/datasets бумалары ашылған жинақтың
ішінде қалуы үшін labs ішінде орналасқан.
Іске қосу үшін скриптті басқа бумаға көшіру қажет емес.
Кітапханаларды алғаш орнатқанда интернет қажет; орнатудан кейін
мұнда қолданылатын деректер мен генераторлар жергілікті жұмыс істейді.
Jupyter ресми нұсқаулығы: https://jupyter.org/install

Бастапқы тексеру: Notebook файлының 7 код ұяшығы таза Python атаулар
кеңістігінде орындалған, қателер жоқ, 2 нақты PNG кірістірілген.
Екі баспа мысалы да бөлек тексерілген. Нақты Python кодының бірізді
орындалуы тексерілген; Jupyter kernel арқылы іске қосу мен нақты браузер
интерфейсі мұнда расталмаған.

PDF канондық мәтіннен дербес баспа беттеуімен жасалған.
Рендерден кейін барлық 29 бет қаралған; соңғы бет ішінара толтырылуы
мүмкін. Бөлек PDF беттерінің саны толық толтырылған беттер санын немесе
Microsoft Word беттелуін дәлелдемейді. Өңделетін DOCX бөлек дайындалған,
бірақ оның визуалды рендері мен нақты Word беттелуі әлі тексерілмеген.
DOCX ZIP құрамына енгізілмеген.

Деректер: барлық үш жиынтық толық синтетикалық. Зертхана регрессиясы: 240 жол, 30 белгі, 5 ақпаратты, noise=20, seed 2026, train/test бөлуі 192/48. Сирек оқиғалар: 1200 жол, 10 белгі, 5 ақпаратты және 2 артық, weights=[0.95,0.05], class_sep=1.5, flip_y=0.01, seed 2026, стратификацияланған бөлу 960/240. Класс белгілері кездейсоқ өзгергеннен кейін класс жиіліктері Notebook ішінде есептелген. ch06_learning_regression.csv — 6.3 теориялық суретіне арналған бөлек 320 жол, генератор 3026, train 240 / validation 80; бұл зертхананың test бөлігі емес. CSV ішінде ID, split және train_order сақталған. Синтетикалық деректер адамдар мен жабдықтың нақты бақылауларын сипаттамайды.

Тәжірибе нәтижелері көрсетілген деректерге, бөлуге, генераторға және
бекітілген нұсқаларға қатысты; олар кез келген нақты объектілердегі
сапаға уәде бермейді. Мұндағы test бойынша салыстыру қорытынды тексеру
жауаптары бойынша конфигурация іріктеуге рұқсат емес.

УМО-ға ұсыну алдында авторлық ғылыми қайта өңдеу, тәуелсіз рецензиялау
және түпнұсқалық пен ЖИ қолданылуының сыртқы тексеруі қажет.
Гриф алу да, пайыздық шектеулерге сәйкестік те мәлімделмейді.
