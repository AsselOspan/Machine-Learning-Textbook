11-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНЫҢ МАТЕРИАЛДАРЫ

Бұл — 15 тараудан тұратын толық оқулықтың емес, бір тараудың жинағы.

Түпнұсқа құрамы: тараудың PDF, DOCX файлдары, labs ішіндегі Notebook пен скрипт,
requirements.txt және datasets ішіне енгізілген деректер жиынтығы.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны жүйеңіздің стандартты тәсілімен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab11.ipynb ашып, жоғарыдан төмен қарай орындаңыз.
   Jupyter қолданбайтын балама: python labs/lab11.py

Скрипт labs ішінде орналасқан, сондықтан оның салыстырмалы шығыс
figures/datasets қалталары ашылған жинақтың ішінде қалады.
Іске қосу үшін скриптті басқа қалтаға көшіру қажет емес.
Кітапханаларды алғаш орнатқанда интернет қажет; орнатқаннан кейін
осындағы деректер мен генераторлар жергілікті жұмыс істейді.
Jupyter ресми нұсқаулығы: https://jupyter.org/install

Түпнұсқа жинақтың тексеру мәліметтері: Notebook-тың 8 код ұяшығы таза Python
атаулар кеңістігінде орындалған, қате жоқ, 2 нақты PNG кірістірілген.
Екі баспа мысалы бөлек тексерілген. Python-ның бірізді орындалуы тексерілген;
түпнұсқада Jupyter ядросы арқылы іске қосу мен нақты браузер интерфейсі расталмаған.

Түпнұсқа PDF канондық мәтіннен жеке баспа беттеуімен жасалған.
Оның барлық 25 беті рендерден кейін қаралған; соңғы бет ішінара толуы мүмкін.
Жеке PDF беттерінің саны толық толтырылған беттер санын немесе Microsoft Word
беттеуін дәлелдемейді. Түпнұсқа жинаққа өңделетін DOCX енгізілген.
Оның құрылымы тексерілген. Microsoft Word ішіндегі көрнекі беттеу мен
нақты бет саны әлі тексерілмеген.

Деректер: ЗЖ 11 ішінде 224 бақылаудан тұратын синтетикалық күнделікті сұраныс
қатары қолданылады. Алғашқы 203 күн әзірлеуге, соңғы 21 күн test жиынына жатады.
Схема файлы бағандардың қолжетімділігін, бірліктерді және seed 2026 генераторын
сипаттайды. Скрипт CSV-ді қайта жасайды. Теорияда талқыланған мұрағаттық
оқу CSV файлдары зертханалық жұмысқа қажет емес.

Эксперимент нәтижелері көрсетілген деректерге, бөлініске, генераторға және
бекітілген нұсқаларға қатысты; олар кез келген нақты нысанда сапаға уәде бермейді.
Мұндағы test бойынша салыстыру қорытынды тексеру жауаптарымен конфигурация
таңдауға рұқсат болып саналмайды.

УМО-ға ұсынар алдында авторлық ғылыми өңдеу, тәуелсіз рецензиялау және
түпнұсқалық пен ЖИ қолдануды сыртқы тексеру қажет.
Гриф алу да, пайыздық шектеулерге сәйкестік те мәлімделмейді.

Қазақша жинаққа қатысты ескертпе:
Жоғарыдағы PDF/DOCX туралы мәліметтер түпнұсқаның тарихи күйін сипаттайды.
Орысша баспа файлдары осы зертханалық қалтаға көшірілмеген; қазақша баспа
нұсқалары жобаның PDF және DOCX бөлімдерінде бөлек дайындалады.
Осы қалтадағы скрипт, Notebook, түсіндірмелер мен график жазулары қазақшаланған.
Модель API, өріс атаулары, тәжірибе сандары және уақыттық хаттама сақталған.
Қазақша нұсқаның нақты тексеру нәтижесі QA_KK.json ішінде беріледі.
