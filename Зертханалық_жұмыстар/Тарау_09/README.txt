# 9-тарау. Жұмыс қолжазбасына арналған материалдар

Бұл — 15 тараудан тұратын толық оқулық емес, бір тараудың жинағы.

Құрамы: тараудың PDF және DOCX файлдары, labs қалтасындағы Notebook пен скрипт,
requirements.txt, сондай-ақ datasets қалтасына енгізілген деректер жиыны.
Қазақша басылымның PDF және DOCX файлдары негізгі жобаның тиісті қалталарында
бөлек құрастырылады; бастапқы орысша баспа файлдары осы зертханаға көшірілмеген.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны жүйеңізге арналған стандартты тәсілмен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab09.ipynb файлын ашып, жоғарыдан төмен орындаңыз.
   Jupyter қолданбайтын балама: python labs/lab09.py

Скрипт labs ішінде орналасқан, сондықтан оның салыстырмалы шығыс қалталары
figures/datasets ашылған жинақ ішінде қалады.
Іске қосу үшін скриптті басқа қалтаға көшіру қажет емес.
Кітапханаларды алғаш орнатқанда интернет қажет; орнатудан кейін
мұнда қолданылатын деректер мен генераторлар жергілікті жұмыс істейді.
Jupyter ресми нұсқаулығы: https://jupyter.org/install

Бастапқы жинақтағы тексеру: Notebook-тің 8 код ұяшығы таза Python атаулар
кеңістігінде орындалған, қате жоқ, 2 нақты PNG ендірілген. Екі баспа мысалы
бөлек тексерілген. Онда нақты Python тізбекті орындалуы ғана тексерілген;
Jupyter ядросы мен нақты браузер интерфейсіндегі іске қосу расталмаған.
Қазақша нұсқаның нақты ядро, сандық нәтижелер және суреттер бойынша тексеруі
негізгі жобаның _work/qa/ch09_kernel.json есебінде бөлек тіркеледі.

Бастапқы PDF канондық мәтіннен дербес баспа беттеуімен жасалған.
Рендерден кейін барлық 26 беті қаралған; соңғы бет ішінара толуы мүмкін.
Жеке PDF беттерінің саны толық толған жолақтар санын немесе Microsoft Word
беттелуін дәлелдемейді. Бастапқы жинақта өңделетін DOCX болған. Оның құрылымы
тексерілген. Microsoft Word ішіндегі визуалды беттелуі мен нақты бет саны
әлі тексерілмеген. Бұл деректер бастапқы басылымға қатысты; қазақша баспа
тексеруі негізгі жобада жеке жүргізіледі.

Деректер: регрессия тәжірибесінде Friedman1 синтетикалық 600 жолын скрипт жасайды. train/validation/test бөлінуі 360/120/120. WDBC 569 жол мен 30 сандық белгіні қамтиды, UCI DOI 10.24432/C5DW2B, CC BY 4.0. Қатерлі класс 1 деп белгіленген. Train/test 455/114, оң объектілер 170/42. CSV және дереккөз туралы мәліметтер datasets ішінде орналасқан. Сипатталған салыстырулар осы деректерде оқу мақсатында жүргізілген.

Тәжірибе нәтижелері көрсетілген деректерге, бөлінуге, генераторға және
бекітілген нұсқаларға қатысты; олар кез келген нақты объектідегі сапаға
уәде бермейді. Мұндағы test бойынша салыстыру қорытынды тексеру жауаптары
бойынша конфигурация іріктеуге рұқсат болып табылмайды.

ОӘБ-ке ұсынудан бұрын авторлық ғылыми қайта өңдеу, тәуелсіз рецензиялау және
түпнұсқалық пен ЖИ қолданылуын сыртқы тексеру қажет.
Гриф алу да, пайыздық шектеулерге сәйкестік те мәлімделмейді.
