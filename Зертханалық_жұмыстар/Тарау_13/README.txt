13-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНА АРНАЛҒАН МАТЕРИАЛДАР

Бұл — 15 тараулы толық оқулық емес, бір тараудың жинағы.

Құрамы: labs бумасындағы Notebook пен скрипт, requirements.txt,
сондай-ақ datasets ішіне енгізілген деректер атрибуциясы. Қазақша тараудың
DOCX және PDF басылымдарын негізгі қазақша жинақтан алыңыз.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны жүйеңізге арналған қалыпты тәсілмен белсендіріңіз.
3. python -m pip install -r requirements.txt
   13-зертханалық жұмыс үшін: python models/fetch_squeezenet_weights.py
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab13.ipynb ашып, жоғарыдан төмен қарай орындаңыз.
   Jupyter қолданбайтын балама: python labs/lab13.py

Скрипт labs ішінде орналасқандықтан, оның салыстырмалы шығыс бумалары
figures/datasets ашылған жинақ ішінде қалады.
Іске қосу үшін скриптті басқа бумаға көшіру қажет емес.
Рецепт Python 3.12 бар Windows x64 жүйесінде, CPU-да тексерілді. Алғашқы
кітапханалар орнатуы мен ресми салмақтарды жүктеу үшін интернет қажет.
Дайындықтан кейін зертханалық жұмыс жергілікті орындалады. Салмақтар
файлының өлшемі шамамен 5 МБ. Дереккөз бен күтілетін SHA-256 мәні
models/SqueezeNet_Weights.txt ішінде сақталған. Бұрын тексерілген жергілікті
файл болса, скриптке --weights беріңіз, ал Notebook ядросының ортасында
LAB13_WEIGHTS_PATH көрсетіңіз. Тексерілген файл қайта жүктелмейді.
Ресми Jupyter нұсқаулығы: https://jupyter.org/install

Бастапқы орысша жинақта 8 кодтық ұяшық таза Python атаулар кеңістігінде
ретімен орындалып, 2 нақты PNG енгізілген; екі баспа мысалы бөлек тексерілген.
Бұл тарихи тексеру нақты Jupyter ядросын растаған жоқ. Қазақша нұсқада
скрипт қайта орындалды және Notebook барлық 8 кодтық ұяшығы нақты жеке
Jupyter/IPython ядросында жоғарыдан төмен орындалды; нақты тексеру
хаттамасы негізгі жинақтың _work/qa/ch13_notebook_kernel.json файлында.
Нақты браузер интерфейсі осы тексеруге кірмейді.

Бастапқы орысша PDF канондық мәтіннен дербес баспа беттеуімен жасалған.
Оның 22 беті рендерден кейін қаралған; соңғы бет ішінара толуы мүмкін.
Жеке PDF беттерінің саны толық толтырылған жолақтар санын немесе
Microsoft Word пагинациясын дәлелдемейді. Бастапқы жинақта құрылымы
тексерілген өңделетін DOCX бар; Microsoft Word ішіндегі көрнекі беттеуі мен
нақты пагинациясы сол жинақта тексерілмеген. Қазақша DOCX/PDF үшін негізгі
басылымның жеке баспа тексеру хаттамасын қараңыз.

Деректер: 13-зертханалық жұмыс кіріктірілген sklearn.datasets.load_digits
жиынын, 1797 бейнені пайдаланады. Дереккөз Alpaydin, E. & Kaynak, C. (1998),
UCI, DOI 10.24432/C50P49, CC BY 4.0. Бекітілген оқу бөлінімі 600/200/250,
747 бейне қатыспайды. Атрибуция мен түрлендірулер сипаттамасы datasets
ішінде сақталған.

Тәжірибе нәтижелері көрсетілген деректерге, бөлінімге, генераторға және
бекітілген нұсқаларға қатысты; олар кез келген нақты нысанда сапаға кепіл
бермейді. Мұндағы test салыстыруы қорытынды тексеру жауаптары бойынша
конфигурация баптауға рұқсат болып саналмайды.

ОӘБ-ке тапсыру алдында авторлық ғылыми қайта өңдеу, тәуелсіз рецензиялау
және түпнұсқалық пен ЖИ қолданылуын сыртқы тексеру қажет. Гриф алынғаны да,
пайыздық шектеулерге сәйкестік те мәлімделмейді.

Windows-та өте терең ішкі каталогтардан іске қоспаңыз: кейбір орталарда
файл жолына 260 таңба шегі қолданылады. Осы жинақтың түбірінен не labs
бумасынан іске қосу тексерілген жол ұзындығына сай келеді. Ұзын басқа
орыннан орындағанда жинақты қысқа жолға, мысалы C:\ML\ch13, көшіріңіз.
Ғылыми кодты, деректерді және параметрлерді өзгертудің қажеті жоқ.
