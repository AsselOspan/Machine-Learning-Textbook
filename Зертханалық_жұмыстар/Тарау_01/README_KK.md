# 1-тараудың зертханалық материалдары

Бұл комплект 1-тараудың зертханалық жұмысына арналған. Онда `labs/lab01.ipynb`, `labs/lab01.py`, `requirements.txt` және нәтижелердің графиктері берілген. Тараудың PDF және DOCX нұсқалары оқулықтың тиісті каталогтарында дайындалады. Зертханалық комплекті бүкіл 15 тараулық оқулықпен шатастырмаңыз.

Жаңа Python 3.12 ортасында іске қосу реті

1. `python -m venv .venv` командасымен орта жасаңыз.
2. Өз жүйеңізге арналған қалыпты тәсілмен ортаны белсендіріңіз.
3. `python -m pip install -r requirements.txt` командасын орындаңыз.
4. Notebook интерфейсі қажет болса, `python -m pip install jupyterlab` командасын орындаңыз.
5. Осы комплект каталогынан `jupyter lab` іске қосыңыз. `labs/lab01.ipynb` файлын ашып, ұяшықтарды жоғарыдан төмен орындаңыз.

Jupyter қолданбай орындау үшін `python labs/lab01.py` командасын пайдаланыңыз. Скрипт `labs` ішінде сақталған, ал оның салыстырмалы шығыс жолдары комплектінің ішінде қалады. Оны басқа каталогқа көшіріп іске қосудың қажеті жоқ. Notebook графиктерді `labs/lab01_figures` ішінде жасайды, скрипттің графиктері `figures` ішінде орналасады.

Кітапханаларды алғаш орнату кезінде интернет қажет. Орнатудан кейін мұнда қолданылатын деректер мен генераторлар жергілікті жұмыс істейді. Jupyter-дің ресми орнату нұсқаулығы берілген. [Jupyter орнату](https://jupyter.org/install)

Қазақша Notebook жеке IPython ядросында толық орындалды. Бес код ұяшығы қатесіз аяқталды, екі нақты PNG шығысқа кірістірілді. Класстар құрамы, іріктемелердің өлшемдері және сандық метрикалар бастапқы тәжірибемен сәйкес келді. Ядро іске қосылғаннан кейін тоқтатылды. Браузер интерфейсінің жұмысы осы тексеруге кірген жоқ. Сақталған шығыс өз бетіңізше талдау жасауды алмастырмайды.

Екінші мысал толығымен синтетикалық. Оның генератор seed мәні 2026. Ол нақты университетті, ғимаратты немесе датчиктерді сипаттамайды. Эксперимент нәтижелері көрсетілген деректерге, бөлуге, генераторға және бекітілген нұсқаларға қатысты. Олар кез келген нақты объектіде сондай сапа болады деп уәде етпейді. Test бойынша салыстыру қорытынды тексерудің жауаптарына қарап конфигурация таңдауға рұқсат бермейді.

Тараудың PDF пішімі канондық мәтіннен жеке баспа беттеуімен жасалады. Редакцияланатын DOCX-тің құрылымдық тексеруі мен Word-тағы нақты беттелуі бөлек рәсімдер болып саналады. Олардың ағымдағы мәртебесін оқулықтың қорытынды QA есебінен қараңыз.

УМО-ға ұсыну алдында авторлық ғылыми редакция, тәуелсіз рецензия және түпнұсқалық пен жасанды интеллектіні пайдалануды сыртқы тексеру қажет. Бұл комплект грифтің алынғанын немесе пайыздық шектеулерге сәйкестікті растамайды.
