3-ТАРАУ. ҚАЗАҚША ЗЕРТХАНАЛЫҚ МАТЕРИАЛДАР

Бұл — бір тараудың зертханалық жиынтығы. Толық оқулық пен тараудың
DOCX/PDF және веб-нұсқасын негізгі жинақтан қараңыз. Бұл папкада labs
ішіндегі Notebook пен скрипт, requirements.txt, datasets деректері,
орындалған есептеулер және figures суреттері сақталған.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны өз жүйеңіздің стандартты тәсілімен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. Осы Тарау_03 папкасынан jupyter lab командасын орындаңыз;
   labs/lab03.ipynb файлын ашып, ұяшықтарды жоғарыдан төмен іске қосыңыз.
   Jupyter қолданбайтын балама: python labs/lab03.py

Скрипттің figures/datasets шығыстары осы жинақ ішінде қалады.
Скриптті басқа папкаға көшіру қажет емес. Notebook шығыстары іске қосу
папкасындағы lab03_artifacts/figures және lab03_artifacts/datasets
ішіне жазылады. Кітапхана атаулары, API, seed, бағандар мен файл
идентификаторлары орысша эталондағыдай сақталған. Мәтін, түсіндірмелер
және графиктегі жазулар қазақшаланған.
Алғашқы орнатуға интернет қажет; орнатудан кейін мұндағы деректер
мен генераторлар жергілікті жұмыс істейді.
Jupyter ресми нұсқаулығы: https://jupyter.org/install

Нақты тексеру: bundled Python арқылы жеке скрипт орындалды; Notebook
nbclient басқаратын шынайы Jupyter kernel ішінде таза күйден орындалды.
5 код ұяшығы [1,2,3,4,5] ретімен өтті, қате жоқ, 2 нақты PNG кірістірілді.
Толық метрика/коэффициент JSON-ы орысша эталонмен дәл тең. Деректер
CSV файлдары эталонмен байт бойынша салыстырылды. Алты қазақша
сурет original режимінде жеке қаралды. Браузер интерфейсі, Word
және DOCX/PDF пагинациясы осы зертханалық тексеруде бағаланған жоқ.
Машинамен оқылатын дәлелдер негізгі Kaz папкасындағы
_work/translation_notes/ch03_assets және ch03.md журналында берілген.

Деректер: synthetic_quadratic_regression.csv толық синтетикалық:
500 жол, seed 2026; генератор мен жауап ережесі labs/lab03.py ішінде.
Wine — scikit-learn кіріктірілген көшірмесі: 178 бақылау, 13 белгі,
3 класс. Aeberhard, S. & Forina, M. (1992), UCI,
DOI 10.24432/C5PC7J, https://archive.ics.uci.edu/dataset/109/wine ;
CC BY 4.0 лицензиясы. Бастапқы 1–3 класс белгілері 0–2 ретінде берілген.
Лицензия мен экспорт сипаттамасы datasets/Wine_Attribution.txt ішінде
түпнұсқа тілінде сақталған.

Тәжірибе нәтижелері көрсетілген деректерге, бөлінуге, генераторға
және бекітілген нұсқаларға қатысты. Олар кез келген шынайы нысанда
осындай сапаға кепілдік бермейді. Мұндағы test бойынша салыстыру
қорытынды тексеру жауаптарына қарап конфигурацияны баптауға рұқсат емес.

УМО-ға ұсынудан бұрын автордың ғылыми өңдеуі, тәуелсіз рецензиялау
және түпнұсқалық пен ЖИ қолданылуын сыртқы тексеру қажет.
Гриф алу немесе пайыздық шектеулерге сәйкестік туралы мәлімдеме жоқ.
