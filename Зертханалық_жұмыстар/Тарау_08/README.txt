8-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНА АРНАЛҒАН МАТЕРИАЛДАР

Бұл — 15 тараудан тұратын толық оқулық емес, бір тараудың жиынтығы.

Құрамы: labs қалтасындағы Notebook пен скрипт, requirements.txt,
сондай-ақ datasets ішіндегі деректер жиынтығы. Тараудың қазақша PDF және DOCX
нұсқалары оқулықтың ортақ PDF және DOCX каталогтарында бөлек дайындалады.
Орысша баспа файлдары осы қазақша зертханалық жиынтыққа көшірілмеген.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны жүйеңіздің қалыпты тәсілімен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab08.ipynb файлын ашып, жоғарыдан төмен орындаңыз.
   Jupyter қолданбайтын балама: python labs/lab08.py

Скрипт labs ішінде орналасқан, сондықтан оның салыстырмалы figures/datasets
шығыс қалталары мұрағаттан шығарылған жиынтық ішінде қалады.
Іске қосу үшін скриптті басқа қалтаға көшіру қажет емес.
Кітапханаларды алғаш орнатқанда интернет керек; орнатқаннан кейін
мұнда қолданылған деректер мен генераторлар жергілікті жұмыс істейді.
Jupyter ресми нұсқаулығы: https://jupyter.org/install

Бастапқы нұсқаны тексеру: Notebook-тің 8 код ұяшығы таза Python атаулар
кеңістігінде орындалған, қате жоқ, 2 нақты PNG енгізілген. Екі баспа мысалы
бөлек тексерілген. Онда тек Python-ның ретімен орындалуы тексерілген;
Jupyter ядросы арқылы іске қосу мен нақты браузер интерфейсі расталмаған.
Қазақша нұсқадағы нақты ядро тексеруінің нәтижесі
../../_work/qa/ch08_kernel/kernel_report.json файлында бөлек тіркеледі.

Бастапқы PDF канондық мәтіннен дербес баспа беттеуі арқылы жасалған.
Оның барлық 32 беті рендерден кейін қаралған; соңғы бет жартылай толуы
мүмкін. Жеке PDF беттерінің саны толық толған беттер санын немесе
Microsoft Word пагинациясын дәлелдемейді. Бастапқы жиынтыққа өңделетін
DOCX кірген. Оның құрылымы тексерілген. Microsoft Word ішіндегі көрнекі
беттеуі мен нақты пагинациясы әлі тексерілмеген.

Деректер: Iris-те 150 бақылау, төрт сандық белгі және үш түр бар.
Дереккөз: Fisher, R. (1936), UCI, DOI 10.24432/C56C76, CC BY 4.0.
Экспорт scikit-learn-нің түзетілген кіріктірілген көшірмесін пайдаланады.
Сипаттамалық кластерлеуде fit барлық 150 жолдың белгілерін пайдаланады.
PCA тәжірибесінде 120 оқыту және 30 кейінге қалдырылған жол түр
белгілерінсіз, seed 2026 арқылы бөлінген. Құрамы мен түрлендірулер
 datasets/Iris_Attribution.txt файлында сипатталған.

Эксперимент нәтижелері көрсетілген деректерге, бөлуге, генераторға және
бекітілген нұсқаларға қатысты; олар кез келген нақты объектілердегі
сапаға уәде бермейді. Мұнда test бойынша салыстыру қорытынды тексерудің
жауаптарына қарап конфигурация таңдауға рұқсат емес.

ОӘБ-ке ұсынар алдында авторлық ғылыми өңдеу, тәуелсіз рецензиялау және
түпнұсқалық пен ЖИ қолдануды сырттай тексеру қажет. Гриф алу да,
пайыздық шектеулерге сәйкестік те мәлімделмейді.

Қазақша нұсқаны нақты тексеру: 8 бастапқы код ұяшығы Jupyter-дің
CurveZMQ ядросында ретімен, қатесіз орындалды; ядро тоқтатылды.
JSON нәтижелері бастапқы орысша және қазақша CLI нәтижелерімен дәл сәйкес.
CSV байттары өзгермеген. Екі енгізілген PNG қазақша CLI графиктерімен
бірдей. Браузер интерфейсі бұл тексеруде ашылмаған.
