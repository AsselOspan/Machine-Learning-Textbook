15-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНЫҢ МАТЕРИАЛДАРЫ

Бұл — 15 тараулы толық оқулықтың бір тарауына арналған жинақ.

Құрамы: labs бумасындағы Notebook пен скрипт, requirements.txt,
requirements-core.txt, datasets ішіндегі деректер жиынтығы және models
ішіндегі жүктегіш, манифест пен салмақтар туралы нұсқаулық.
Қазақша тараудың PDF/DOCX басылымдарын баспа жинағы бөлек береді.
Бастапқы орысша PDF/DOCX бұл зертханалық бумаға көшірілмеген.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны жүйеңіздің стандартты тәсілімен белсендіріңіз.
3. python -m pip install -r requirements.txt
   ЗЖ 15 үшін: python models/fetch_flan_t5_small.py
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab15.ipynb файлын ашып, жоғарыдан төмен орындаңыз.
   Jupyter қолданбайтын балама: python labs/lab15.py

Скрипт labs ішінде орналасқан, сондықтан оның салыстырмалы шығыс бумалары
figures/datasets ашылған жинақ ішінде қалады.
Іске қосу үшін скриптті басқа бумаға көшіру қажет емес.
Рецепт Windows x64, Python 3.12 және CPU ортасында тексерілген. Кітапханаларды
орнатуға және модель файлдарын алғаш жүктеуге (шамамен 311 МБ) интернет қажет.
Генерация тек жергілікті тексерілген файлдарды пайдаланады.
Дереккөз, лицензия және SHA-256 models ішінде көрсетілген.
Ресми Jupyter нұсқаулығы: https://jupyter.org/install

Бастапқы жинақтың тексеру тарихы: бөлек IPython ядросында Notebook-тың
8 код ұяшығы орындалған, қате жоқ, 2 нақты PNG енгізілген. Екі баспа мысалы
бөлек тексерілген. Сандық нәтижелер мен кескіндер скрипт іске қосуымен сәйкес.
Браузер интерфейсі бөлек тексерілмеген.
Қазақша нұсқаны жаңа тексерудің нақты түбіртегі _work/qa ішіндегі
ch15_notebook_kernel.json файлында: нақты ядро, CLI және бастапқы нәтижелер
барлық ғылыми JSON өрістері бойынша салыстырылады; орта нұсқалары бөлек жазылады.

Бастапқы PDF канондық мәтіннен дербес баспа беттеуімен жасалған.
Рендерден кейін барлық 27 бет қаралған; соңғы бет жартылай толуы мүмкін.
Жеке PDF бет саны толық толған жолақтар санын немесе Microsoft Word
пагинациясын дәлелдемейді. Бастапқы жинақта құрылымы тексерілген өңделетін
DOCX бар. Microsoft Word ішіндегі көрнекі беттеу мен нақты пагинация
әлі тексерілмеген. Бұл тарихи мәлімет қазақша басылымның беттеуін растамайды.

Деректер: авторлық ойдан шығарылған анықтамалар, 2 әзірлеу және 14 тест
мысалы. Корпус, бақылау үзінділері және бекітілген хаттама
datasets/synthetic_grounded_qa.json ішінде. Деректер оқу есептеріне жатады.

Локализация шекарасы: README, Notebook Markdown ұяшықтары, код түсініктемелері,
қате/көмек хабарлары мен график жазулары қазақшаланған. Ағылшын тіліндегі
тәжірибе сұрақтары, құжаттар, модель промпттары, эталон жолдары және жауаптар
аударылмаған: оларды өзгерту модельге берілетін тәжірибені өзгертер еді.
Корпус байттары, оның SHA-256 мәні, файл атаулары, API, JSON машиналық
кілттері және нәтиже кодтары сақталған. Бұл тәжірибе қазақша генерация сапасын
өлшемейді; қазақша мәтін ағылшынша бекітілген тәжірибені түсіндіреді.

Тасымалданатын жинаққа модель салмақтары мен кэш кірмейді.
models/fetch_flan_t5_small.py және flan_t5_small_manifest.json нақты ревизияны,
өлшемдер мен хештерді сақтайды; файлдар бар болса жүктегіш тек оларды тексереді.
Локализация QA іске қосуында бұрын тексерілген бастапқы салмақтар тек оқылды,
қайта желілік жүктеу жасалмады. Ортаға тәуелді жергілікті абсолютті жолдар
студенттік Notebook көзіне енгізілмеген.

Тәжірибе нәтижелері көрсетілген деректерге, бөлуге, генераторға және бекітілген
нұсқаларға қатысты; олар кез келген нақты нысанда сапаға уәде бермейді.
Мұндағы test салыстыруы қорытынды тексеру жауаптары бойынша конфигурация
таңдауға рұқсат болып саналмайды.

ОӘБ-ке ұсыну алдында авторлық ғылыми өңдеу, тәуелсіз рецензиялау және
түпнұсқалық пен ЖИ пайдаланылуын сыртқы тексеру қажет.
Гриф алу да, пайыздық шектеулерге сәйкестік те мәлімделмейді.
