4-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНА АРНАЛҒАН МАТЕРИАЛДАР

Бұл — 15 тараудан тұратын толық оқулық емес, бір тараудың жинағы.

Құрамы: labs каталогындағы Notebook пен скрипт, requirements.txt,
сондай-ақ datasets каталогындағы деректер жиынтықтары. Бастапқы жинақтағы
орысша PDF пен DOCX көшірілмеді. Қазақша тараудың мәтіні негізгі жобаның
Мәтіндер/ch04.md файлында; қазақша PDF/DOCX негізгі жобада бөлек әзірленеді.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаңызды өз жүйеңізге арналған стандартты тәсілмен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab04.ipynb файлын ашып, жоғарыдан төменге орындаңыз.
   Jupyter қолданбайтын балама: python labs/lab04.py

Скрипт labs ішінде орналасқан, сондықтан оның салыстырмалы шығыс
figures/datasets каталогтары ашылған жинақтың ішінде қалады.
Іске қосу үшін скриптті басқа каталогқа көшіру қажет емес.
Кітапханаларды алғаш орнатқанда интернет керек; орнатқаннан кейін
осында қолданылатын деректер мен генераторлар жергілікті жұмыс істейді.
Ресми Jupyter нұсқаулығы: https://jupyter.org/install

Бастапқы жинақта Notebook-тің 6 код ұяшығы таза Python кеңістігінде
тізбекті орындалған, қате болмаған және 2 нақты PNG енгізілген деп көрсетілген.
Баспа нұсқасындағы екі мысал да бөлек тексерілген. Бастапқы README-де
Jupyter ядросы мен нақты браузер интерфейсі арқылы іске қосу расталмаған.
Қазақша нұсқада код пен түсіндірмелер аударылып, ескі шығыстар тазартылды;
нақты Jupyter ядросында тексеру сәтті өтті: 6 код ұяшығы, қате жоқ, 2 PNG бар. Нәтиже негізгі жобадағы
_work/qa/ch04_notebook_kernel.json есебіне жазылды.
Браузердегі Jupyter интерфейсінің тексерілгені туралы мәлімдеме жасалмайды.

Бастапқы PDF канондық мәтіннен бөлек баспа беттеу арқылы жасалған.
Дереккөз README-іне сәйкес, оның 29 беті рендерден кейін қаралған; соңғы
бет жартылай толуы мүмкін. Жеке PDF беттерінің саны толық толған жолақтар
санын не Microsoft Word пагинациясын дәлелдемейді. Бастапқы жинақтағы
өңделетін DOCX құрылымы тексерілген, ал Microsoft Word-тағы көрнекі беттеу
мен нақты пагинация тексерілмеген. Бұл бастапқы орысша басылымның
тексерулері қазақша PDF/DOCX тексерулерінің орнына жүрмейді.

Деректер: synthetic_moons.csv екі доғасы толық синтетикалық: make_moons,
600 жол, noise=0.2, seed 2026. Digits — scikit-learn кіріктірілген көшірмесі,
8×8 өлшемді 1797 кескін, 64 белгі, 10 класс. Alpaydin, E. & Kaynak, C. (1998),
UCI, DOI 10.24432/C50P49, CC BY 4.0. Көшірме бастапқы UCI тест бөлігіне
сәйкес келеді; оның ішіндегі жаңа 1437/360 оқу бөлінісі бастапқы UCI
benchmark тәжірибесін қайталамайды. Дереккөз, лицензия және экспорт
сипаттамасы datasets/Digits_Attribution.txt ішінде сақталған.

Тәжірибе нәтижелері көрсетілген деректерге, бөлініске, генераторға және
бекітілген нұсқаларға қатысты; олар кез келген нақты объектідегі сапаны
уәде етпейді. Мұндағы test бойынша салыстыру қорытынды тексеру жауаптары
бойынша конфигурацияны баптауға рұқсат болып саналмайды.

түпнұсқалық пен ЖИ қолданылуын сыртқы тексеру қажет.
