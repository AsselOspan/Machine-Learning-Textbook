7-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНА АРНАЛҒАН МАТЕРИАЛДАР

Бұл — 15 тараулы толық оқулық емес, бір тараудың жинағы.

Құрамы: тараудың PDF нұсқасы, labs бумасындағы Notebook пен скрипт,
requirements.txt, сондай-ақ datasets ішіне енгізілген болса, деректер жиынтығы.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны жүйеңізге тән стандартты тәсілмен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab07.ipynb файлын ашып, жоғарыдан төмен орындаңыз.
   Jupyter-сіз балама: python labs/lab07.py

Скрипт labs ішінде орналасқан, сондықтан оның салыстырмалы шығыс
figures/datasets бумалары ашылған жинақтың ішінде қалады.
Іске қосу үшін скриптті басқа бумаға көшіру қажет емес.
Кітапханаларды алғаш орнатқанда интернет қажет; орнатқаннан кейін
мұндағы деректер мен генераторлар жергілікті жұмыс істейді.
Jupyter ресми нұсқаулығы: https://jupyter.org/install

Тексеру: таза Python атаулар кеңістігінде Notebook-тің 8 код ұяшығы орындалған,
қате жоқ, 2 нақты PNG ендірілген. Екі баспа мысалы бөлек тексерілген.
Дәл Python-ның тізбекті орындалуы тексерілген; Jupyter kernel арқылы іске
қосу мен нақты браузер интерфейсі мұнда расталмаған.

PDF канондық мәтіннен дербес баспа беттеуімен жасалған.
Рендерден кейін барлық 28 бет қаралған; соңғы бет жартылай толуы мүмкін.
Жеке PDF беттерінің саны толық толған баспа беттерінің санын немесе
Microsoft Word пагинациясын дәлелдемейді. Өңделетін DOCX бөлек дайындалған,
бірақ оның визуалды рендері мен нақты Word пагинациясы әлі тексерілмеген.
DOCX ZIP ішіне кірмейді.

Деректер: Wine: scikit-learn кіріктірілген көшірмесі, 178 бақылау, 13 белгі, 3 класс; Aeberhard, S. & Forina, M. (1992), UCI, DOI 10.24432/C5PC7J, https://archive.ics.uci.edu/dataset/109/wine , CC BY 4.0. Бастапқы жиынның 1–3 кластары 0–2 түрінде берілген. Wine_search.csv CSV файлы train/test бөлік белгісін сақтайды, бөлінісі 142/36. Grid/Random және ішкі-сыртқы CV тек рұқсат етілген бөліктерді пайдаланады. Жеке оқу GP/EI іздеуі test берілместен train бойынша орындалады; оның 28 Pipeline-fit және 6 GPR-fit-і бөлек есептеледі. Дереккөз бен лицензия datasets/Wine_Attribution.txt ішінде сақталған.

Эксперимент нәтижелері көрсетілген деректерге, бөлініске, генераторға және
бекітілген нұсқаларға қатысты; олар кез келген нақты нысанда сапаға уәде
бермейді. Мұндағы test бойынша салыстыру қорытынды тексеру жауаптарымен
конфигурация таңдауға рұқсат емес.

УМО-ға тапсыру алдында авторлық ғылыми өңдеу, тәуелсіз рецензиялау және
түпнұсқалық пен ЖИ қолданылуын сыртқы тексеру қажет. Гриф алу да,
пайыздық шектеулерге сәйкестік те мәлімделмейді.

Қазақша локализацияға ескерту

сипаттайды. Қазақша жинаққа орысша PDF/DOCX енгізілмейді; қазақша баспа
