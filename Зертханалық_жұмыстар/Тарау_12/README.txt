12-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНЫҢ МАТЕРИАЛДАРЫ

Бұл — 15 тараудан тұратын толық оқулық емес, бір тараудың жинағы.

Құрамы: labs каталогындағы Notebook пен скрипт, requirements.txt,
datasets каталогындағы деректер жиынтығы және атрибуция.
Қазақша тараудың PDF және DOCX нұсқаларын оқулықтың ортақ PDF және DOCX
каталогтарынан қараңыз. Бастапқы орысша PDF пен DOCX бұл жинаққа кірмейді.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны жүйеңіздегі стандартты тәсілмен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab12.ipynb файлын ашып, жоғарыдан төмен орындаңыз.
   Jupyter қолданбайтын балама: python labs/lab12.py

Скрипт labs каталогында орналасқан: сондықтан оның figures/datasets
салыстырмалы каталогтары архивтен шығарылған жинақ ішінде қалады.
Іске қосу үшін скриптті басқа каталогқа көшіру қажет емес.
Кітапханаларды алғаш орнатқанда интернет керек; орнатудан кейін
мұнда қолданылатын деректер мен генераторлар жергілікті орындалады.
Jupyter ресми нұсқаулығы: https://jupyter.org/install

Тексеру: қазақшаланған скрипт пен Notebook үшін нақты орындалу деректері
оқулықтың _work/qa/ch12_assets_audit.json және ch12_kernel_qa.json
файлдарында тіркеледі. Notebook жергілікті бөлек IPython ядросында
орындалады. Нақты браузер интерфейсінде қолмен іске қосу тексерілмеген.
Бастапқы жинақтағы 8 код ұяшығы, екі PNG және бөлек тексерілген екі
баспа мысалы туралы мәлімет қазақша нұсқа үшін қайта тексеріледі.

Баспа нұсқалары туралы бастапқы жинақ мәліметі: орысша PDF канондық
мәтіннен тәуелсіз беттелген, оның 24 беті рендерден кейін қаралған,
соңғы бет ішінара толуы мүмкін. Жеке PDF беттерінің саны толық толған
баспа беттері санын немесе Microsoft Word беттелуін дәлелдемейді.
Бастапқы өңделетін DOCX құрылымы тексерілген, бірақ Microsoft Word
ішіндегі көрнекі беттеу мен нақты бет саны тексерілмеген.
Бұл мәліметтер қазақша басылымның тексеруін алмастырмайды; оның күйі
оқулықтың ортақ сапа есебінде беріледі.

Деректер: №12 зертханалық жұмыста Yelp ішкі жиынының 1000 сөйлемі,
UCI Sentiment Labelled Sentences, DOI 10.24432/C57604, CC BY 4.0
пайдаланылады. Бастапқы TSV өзгеріссіз және атрибуциясымен берілген.
TF-IDF пен оқу SGNS алгоритмі тек train бөлігінде оқытылады.
Notebook пен скрипт жергілікті деректерді пайдаланады.

Тәжірибе нәтижелері көрсетілген деректерге, бөлуге, генераторға және
бекітілген нұсқаларға қатысты; олар еркін нақты объектілерде сапаға
кепілдік бермейді. Мұндағы test салыстыруы қорытынды тексеру жауаптары
бойынша конфигурация таңдауға рұқсат болып саналмайды.

УМО қарауына жіберуден бұрын авторлық ғылыми өңдеу, тәуелсіз рецензия
және түпнұсқалық пен ЖИ пайдаланылуын сыртқы тексеру қажет.
Гриф алу да, пайыздық шектеулерге сәйкестік те мәлімделмейді.
