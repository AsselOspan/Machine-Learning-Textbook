5-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНА АРНАЛҒАН МАТЕРИАЛДАР

Бұл — 15 тараудан тұратын толық оқулық емес, бір тараудың жинағы.

Құрамы: бастапқы жинақта тарау PDF-і, labs қалтасындағы Notebook пен скрипт,
requirements.txt, сондай-ақ datasets ішіне енгізілген деректер жиынтығы бар.
Қазақша зертханалық жинақта Notebook, скрипт, тәуелділіктер және CSV сақталған;
орысша PDF көшірілмеген. Қазақша DOCX/PDF негізгі жобада бөлек дайындалады.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны жүйеңізге тән стандартты тәсілмен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab05.ipynb файлын ашып, жоғарыдан төмен орындаңыз.
   Jupyter-сіз балама: python labs/lab05.py

Скрипт labs ішінде орналасқан, сондықтан оның салыстырмалы figures/datasets
шығыс қалталары ашылған жинақ ішінде қалады.
Іске қосу үшін скриптті басқа қалтаға көшіру қажет емес.
Кітапханаларды алғашқы орнатқанда интернет керек; орнатудан кейін мұндағы
деректер мен генераторлар жергілікті жұмыс істейді.
Jupyter ресми нұсқаулығы: https://jupyter.org/install

Бастапқы жинақтағы тексеру жазбасы: Notebook-тың 7 код ұяшығы таза Python
атаулар кеңістігінде орындалған, қате жоқ, 2 нақты PNG ендірілген.
Екі баспа мысалы бөлек тексерілген. Дәл Python-ды тізбекті орындау
тексерілген; бұл бастапқы жазба Jupyter ядросы мен нақты браузер
интерфейсі арқылы іске қосуды растаған жоқ.
Қазақша нұсқаның нақты ядро тексеруі негізгі жобаның
_work/qa/ch05_kernel/kernel_report.json есебінде бөлек тіркеледі.

Бастапқы жинақтың PDF-і канондық мәтіннен дербес баспа беттеуімен жасалған.
Рендерден кейін барлық 29 беті қаралған; соңғы бет ішінара толуы мүмкін.
Жеке PDF беттерінің саны толық толған беттер санын немесе Microsoft Word
беттелуін дәлелдемейді. Өңделетін DOCX бөлек дайындалған, бірақ оның
көрнекі рендері мен нақты Word беттелуі сол бастапқы жазбада әлі
тексерілмеген. DOCX бастапқы ZIP-ке енгізілмеген.
Бұл тарихи мәлімет қазақша PDF/DOCX тексерілді дегенді білдірмейді.

Деректер: екі мысал да толық жасанды. Сегіз белгі мен ықтималдық қолмен
тексеру үшін кодта тікелей берілген. Негізгі CSV ішінде make_classification
арқылы алынған 1000 жол, 20 белгі, 5 ақпаратты және 2 артық белгі бар;
weights=[0.9,0.1], class_sep=1.2, flip_y=0.02, seed 2026.
600/200/200 бөлінісі және train/validation/test бөлік белгілері CSV-де
сақталған. Бұлар университет, жабдық немесе адамдар туралы нақты мәлімет
емес. Тараудың қосымша жобасы бөлек берілген 1600 жол генерациясын қолданады;
жоба нәтижелері орындалған зертханалық тәжірибе ретінде ұсынылмайды.

Эксперимент нәтижелері көрсетілген деректерге, бөлініске, генераторға және
бекітілген нұсқаларға қатысты; олар кез келген нақты нысандағы сапаға уәде
бермейді. Мұндағы test бойынша салыстыру қорытынды тексеру жауаптары арқылы
конфигурация таңдауға рұқсат емес.

УМО-ға ұсыну алдында авторлық ғылыми қайта өңдеу, тәуелсіз рецензиялау және
түпнұсқалық пен ЖИ қолданылуын сыртқы тексеру қажет.
Гриф алу да, пайыздық шектеулерге сәйкестік те мәлімделмейді.
