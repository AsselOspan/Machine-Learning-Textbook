14-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНА АРНАЛҒАН МАТЕРИАЛДАР

Бұл — 15 тараудан тұратын толық оқулық емес, бір тараудың жинағы.

Құрамы: тарау PDF-і, DOCX, labs бумасындағы Notebook пен скрипт, requirements.txt,
сондай-ақ datasets ішіне енгізілген болса, деректер жиынтығы.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны жүйеңізге тән стандартты тәсілмен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab14.ipynb ашып, жоғарыдан төмен орындаңыз.
   Jupyter қолданбайтын балама: python labs/lab14.py

Скрипт оның салыстырмалы шығыс бумалары figures/datasets
ашылған жинақтың ішінде қалуы үшін labs бумасында орналасқан.
Іске қосу үшін скриптті басқа бумаға көшіру талап етілмейді.
Рецепт Windows x64 және Python 3.12 жүйесінде тексерілген. Кітапханалар орнатылғаннан кейін
жергілікті HTTP тесті үшін тек TCP 127.0.0.1 қолжетімділігі қажет.
MLflow журналды дискіде жүргізеді. Салмақтар мен сыртқы деректер жүктелмейді.
Jupyter ресми нұсқаулығы: https://jupyter.org/install

Бөлек IPython ядросында Notebook-тің 8 код ұяшығы орындалды,
қателер жоқ, 2 нақты PNG ендірілген. Екі баспа мысалы бөлек тексерілген.
Сандық нәтижелер мен суреттер скрипттің іске қосылуымен сәйкес келді.
Браузер интерфейсі бөлек тексерілмеді.

PDF канондық мәтіннен дербес баспа беттеуімен жасалған.
Барлық 24 бет рендерден кейін қаралған; соңғы бет
ішінара толтырылуы мүмкін. Жеке PDF беттерінің саны толық толған
беттер санын немесе Microsoft Word беттелуін дәлелдемейді.
Жинақта өңделетін DOCX бар. Оның құрылымы тексерілген. Microsoft Word бағдарламасындағы көрнекі беттеу мен нақты беттелу әлі тексерілмеген.

Деректер: барлық деректер labs/lab14.py генераторында жасалған. Оларда нақты жабдық көрсетімдері жоқ. Белгілер, бөлулер, ығысу және класс белгілерінің кідіруі datasets/Synthetic_Equipment_Lifecycle.txt файлында сипатталған.

Эксперимент нәтижелері көрсетілген деректерге, бөлуге,
генераторға және бекітілген нұсқаларға қатысты; олар кез келген
нақты объектілерде сапаға уәде бермейді. Мұндағы test салыстыруы
қорытынды тексеру жауаптары бойынша конфигурация таңдауға рұқсат емес.

ОӘБ-ге ұсынудан бұрын авторлық ғылыми өңдеу, тәуелсіз
рецензиялау және түпнұсқалық пен ЖИ қолданылуын сыртқы тексеру қажет.
Гриф алу да, пайыздық шектеулерге сәйкестік те мәлімделмейді.
