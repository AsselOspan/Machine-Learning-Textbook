10-ТАРАУ. ЖҰМЫС ҚОЛЖАЗБАСЫНА АРНАЛҒАН МАТЕРИАЛДАР

Бұл — 15 тараудан тұратын толық оқулық емес, бір тараудың жинағы.

Құрамы: labs бумасындағы Notebook пен скрипт, requirements.txt,
requirements-core.txt, README және datasets ішіндегі деректер жиынтығы.
Қазақша тарау мәтіні негізгі жобаның Мәтіндер/ch10.md файлында орналасқан.
Қазақша баспа нұсқаларын негізгі жобаның DOCX және PDF бумаларынан қараңыз.
Бастапқы орысша PDF пен DOCX бұл қазақша зертханалық жинаққа кірмейді.

Жаңа Python 3.12 ортасында іске қосу:
1. python -m venv .venv
2. Ортаны өз жүйеңіздегі стандартты тәсілмен белсендіріңіз.
3. python -m pip install -r requirements.txt
4. Notebook интерфейсі үшін: python -m pip install jupyterlab
5. jupyter lab — labs/lab10.ipynb ашып, жоғарыдан төмен орындаңыз.
   Jupyter қолданбайтын балама: python labs/lab10.py

Скрипт labs ішінде орналасқан, сондықтан оның figures/datasets салыстырмалы
шығыс бумалары тарқатылған жинақ ішінде қалады.
Іске қосу үшін скриптті басқа бумаға көшіру талап етілмейді.
Кітапханаларды алғаш орнатқанда интернет қажет; орнатудан кейін
мұнда қолданылатын деректер мен генераторлар жергілікті жұмыс істейді.
Jupyter ресми нұсқаулығы: https://jupyter.org/install

Түпнұсқадағы тексеру жазбасы: таза Python атаулар кеңістігінде Notebook
кодтық 8 ұяшығы орындалған, қате жоқ, нақты 2 PNG енгізілген.
Екі баспа мысалы да бөлек тексерілген. Бұл жазба тізбекті Python орындауын
растайды; ол кезде Jupyter ядросы мен нақты браузер интерфейсі расталмаған.
Қазақша нұсқада скрипт бөлек іске қосылып, Notebook нақты Jupyter ядросында
қайта орындалды. Барлық 8 кодтық ұяшық қатесіз орындалып, 2 қазақша PNG
енгізілді. Сандық тәжірибе нәтижелері түпнұсқамен дәл салыстырылды.
Тексеру түбір жобаның _work/qa/ch10_notebook_kernel.json файлында тіркелген.

Түпнұсқа PDF канондық мәтіннен дербес баспа беттеуімен жасалған.
Рендерден кейін оның 28 беті қаралған; соңғы бет ішінара толуы мүмкін.
Жеке PDF беттерінің саны толық толған баспа беттерінің санын немесе
Microsoft Word пагинациясын дәлелдемейді. Түпнұсқаның өңделетін DOCX
құрылымы тексерілген, бірақ Microsoft Word ішіндегі көрнекі беттеу мен
нақты пагинациясы ол тексеруде расталмаған. Бұл тарихи мәлімет қазақша
баспа нұсқаларын тексерудің орнына қолданылмайды.

Деректер: ЗЖ 10 9-тараудың WDBC CSV файлын қайта пайдаланады. Онда 569 жол,
30 сандық белгі және бекітілген 455/114 бөлу бар. Дереккөз UCI,
DOI 10.24432/C5DW2B, CC BY 4.0. 1 класы қатерлі бақылауды білдіреді.
Қосымша жоба II үшін деректерді 10.11-бөлімдегі генератор жасайды.
Бұл бөлім толық қазақшаланған канондық тарауда сақталған; бастапқы жинақта
жоба II үшін бөлек дайын Notebook немесе жауаптар жинағы болмаған.

Тәжірибе нәтижелері көрсетілген деректерге, бөлуге, генераторға және
бекітілген нұсқаларға қатысты; олар кез келген нақты нысандардағы сапаны
уәде етпейді. Мұндағы test салыстыруы түпкілікті тексеру жауаптары бойынша
конфигурация іріктеуге рұқсат болып табылмайды.

УМО-ға ұсынуға дейін авторлық ғылыми өңдеу, тәуелсіз рецензиялау,
түпнұсқалық пен ЖИ қолдануды сыртқы тексеру қажет.
