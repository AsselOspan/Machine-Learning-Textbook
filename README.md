# Машиналық оқыту

**Оспан Әсел Ғалымжанқызы**, әл-Фараби атындағы Қазақ ұлттық университеті, 2026.

Қазақ тіліндегі университеттік электрондық оқулық. Жинақта 15 тарау, 15 зертханалық жұмыс және 3 жоба бар. Сызбалар, формулалар, Python мысалдары, Jupyter Notebook файлдары және өзіндік тексеру тапсырмалары берілген.

[Электрондық оқулықты ашу](https://asselospan.github.io/Machine-Learning-Textbook/) · [Репозиторийдің ZIP көшірмесін жүктеу](https://github.com/AsselOspan/Machine-Learning-Textbook/archive/refs/heads/main.zip)

Тарауларға 15 қадамдық сызба қосылған. Барлық сызба мен Iris деректерін бөлу туралы қысқа бейнесабақ бір бетте жинақталған. Бейнеде қазақша титрлер бар. Сызбаны қадамдап қарауға немесе ойнатуға болады. Сызбалардың қадамдары мен бейне мазмұны мәтін түрінде де берілген.

## Жергілікті пайдалану

1. Репозиторийді көшіріңіз немесе ZIP архивін толық шығарыңыз.
2. Жоғарғы деңгейдегі `index.html` файлын браузерде ашыңыз.
3. Мәзірдегі **Сызбалар мен анимациялар** бетін таңдаңыз немесе кез келген тараудағы **Қадамдық сызба** сілтемесін басыңыз.

Оқу мәтіні, суреттер, іздеу, тесттер, сызбалар және бейне жергілікті файлдардан ашылады. Python зертханалары үшін әр жұмыстың өз нұсқаулығы мен тәуелділіктері бар. Баспа нұсқалары және зертханалық файлдар тиісті беттерден жүктеледі.

## GitHub Pages

1. Осы репозиторийдің `main` тармағына дайын файлдарды Git арқылы жіберіңіз. `index.html` және `.nojekyll` репозиторий түбірінде тұруы керек.
2. Репозиторийде **Settings → Pages → Build and deployment** бөліміне өтіңіз. **Deploy from a branch**, **main**, **/(root)** параметрлерін таңдап, **Save** басыңыз.
3. Жарияланғаннан кейін **Settings → Pages** бөліміндегі **Visit site** сілтемесі арқылы оқулықты ашыңыз.

[GitHub Pages баптау нұсқаулығы](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
